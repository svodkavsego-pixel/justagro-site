Підключення до GitHub

Потрібно один раз, щоб адмінка могла зберігати зміни на сайт.

Як отримати ключ (2 хвилини)
  1. Відкрийте github.com → Fine-grained token.
  2. Token name: JustAgro admin, Expiration: на ваш вибір.
  3. Repository access → Only select repositories → justagro-site.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Натисніть Generate token, скопіюйте його і вставте в поле вище.
Ключ дає доступ лише до цього сайту. Нікому його не пересилайте.

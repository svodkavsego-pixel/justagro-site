# JustAgro - сайт

Статичний сайт (HTML + CSS), без збірки. Vercel публікує його як є.

- index.html - головна сторінка (з перемикачем світлої/темної теми)
- styles.css - стилі і кольори обох тем
- favicon.svg - іконка сайту

Щоб оновити сайт: змініть файл на GitHub, і Vercel сам опублікує нову версію приблизно за 30 секунд.
